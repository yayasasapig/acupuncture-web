🎯 紅色=井 · 黃色=滎 · 綠色=輸 · 粉紅=原 · 青色=經 · 紫色=合

🧩 Pattern 1 — 「同名穴」捷徑

  • 陰經嘅原穴 = 輸穴（同一穴：太淵、大陵、神門、太白、太衝、太谿）
  • 陽經嘅原穴 = 輸穴隔一個（合谷喺三間同陽谿之間）
  • 「商」字輩：少商、商陽、商丘 — 都係經/井穴（金相關）
  • 「陽」字輩：陽谿、陽谷、陽輔、陽陵泉 — 都係經/合穴（陽經專用）
  • 「太」字輩：太淵、太白、太衝、太谿 — 都係輸/原穴 ⭐

🧩 Pattern 2 — 「位置記憶法」

  • 井穴：全部喺手指腳趾尖（指甲旁）
  • 滎穴：全部喺手指腳趾後面嗰節
  • 輸穴：全部喺手掌腳掌關節位
  • 經穴：全部喺手腕腳腕附近
  • 合穴：全部喺手肘膝蓋附近
  • 口訣：「尖→節→掌→腕→肘/膝」

🧩 Pattern 3 — 本穴即係...？

  • 本穴 = 五輸穴中，五行同該經相同嘅那個穴
  • 大腸經（陽金）→ 本穴=商陽（井金）
  • 胃經（陽土）→ 本穴=足三里（合土）← 你識！
  • 心經（陰火）→ 本穴=神門（輸土）？錯！心經係陰火，本穴=少府（滎火）
  • 唔使背：知道條經嘅五行，睇返陰/陽表就知本穴

🧩 Pattern 4 — 「母子補瀉速查」

  • 大腸（陽金）虛 → 補曲池（母/土）✅ 已學
  • 大腸（陽金）實 → 瀉二間（子/水）
  • 胃（陽土）虛 → 補足三里（母/火）⚠️ 足三里本身就係合穴/母穴
  • 胃（陽土）實 → 瀉厲兌（子/金）
  • 心包（陰火）虛 → 補中衝（母/木）
  • 心包（陰火）實 → 瀉大陵（子/土）
  • 記法：母=生我·井向合方向·順推一格 = 母
